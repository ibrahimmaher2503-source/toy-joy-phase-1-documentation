# UI Screen Inventory

## Shared Screen Contract

Every screen row below explicitly inherits this contract unless its row states a stricter behavior:

- **Main states:** default; skeleton/inline `Loading`; contextual `Empty` with permitted next action; recoverable `Error` retaining safe input; `Success` toast/banner and refreshed authoritative data; `Disabled` with reason; `Permission Denied` without record-existence leakage; inline and summary `Validation`; confirmation for sensitive actions; unsaved-change warning for long forms.
- **Responsive:** desktop and tablet first, usable narrow fallback; priority columns collapse to detail/drawer; no essential action clipped; POS retains cart/totals/context; touch targets and keyboard focus remain usable.
- **Direction:** Arabic-first full RTL and English LTR, logical spacing/alignment, locale dates/numbers, intentional icon direction, bilingual labels/fields, text expansion.
- **Data behavior:** authorize and scope before query; server-side search/filter/sort/pagination for lists; eager-loading/bounded queries; sensitive fields redacted; current server values revalidated on action.
- **Flux reuse:** use Flux Button/Input/Textarea/Select/Combobox/Checkbox/Radio/Switch/Table/Pagination/Modal/Dialog/Drawer/Tabs/Date-Time/Calendar/File Upload/Toast/Badge/Breadcrumb/Sidebar/Header/Tooltip/Card/Chart/Loading/Empty/Error components when available. Do not rebuild an existing Flux component.
- **Validation and permissions:** server validation and policy/gate for every action; UI visibility mirrors rights; double-submit protection; confirmation, reason, approval, audit, and state transition where required.
- **Print:** `None` means the screen has no output; otherwise dedicated thermal/A4/PDF/label view uses authoritative snapshots, locale/direction, reprint audit, and no source mutation.

Routes are proposals and must be reconciled with the actual future Laravel project. Implemented rows remain `In Progress` until code review and manual browser evidence; all other screens start `Not Started`.
